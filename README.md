# 🛒 GroceryHub – Online Grocery Delivery System

A modern, responsive, and interactive **Online Grocery Delivery System** built using **HTML5, CSS3, Bootstrap 5, and JavaScript**. GroceryHub provides a realistic grocery shopping experience where users can browse products, filter items, view detailed product information, and manage a shopping cart through a clean and user-friendly interface.

This project is designed as a front-end e-commerce application, focusing on responsive design, intuitive navigation, and interactive user experience without requiring a backend.

---

## 📌 Features

### 🏠 Responsive Home Page
- Modern landing page with hero banner and promotional section
- Featured grocery categories
- Responsive layout using Bootstrap Grid System
- Clean footer with quick links and contact information

### 🧭 Navigation Bar
- Responsive Bootstrap navigation
- Brand logo
- Navigation links:
  - Home
  - Categories
  - Offers
  - Cart
  - Contact
- Live product search functionality

### 🛍️ Product Categories
Products are organized into multiple grocery categories, including:

- 🥦 Fruits & Vegetables
- 🥛 Dairy Products
- 🍪 Snacks
- 🥤 Beverages
- 🧹 Household Essentials

Each product is dynamically rendered using JavaScript and displayed as responsive Bootstrap cards.

### 🎉 Offers & Promotions
- Bootstrap Carousel for promotional banners
- Festival discounts
- Seasonal offers
- Combo deals
- Special grocery discounts

### 📦 Product Details
Each product includes:
- Product image
- Product name
- Price
- Description
- Quantity selector
- Add to Cart button

Displayed using a Bootstrap Modal for a smooth user experience.

### 🔍 Advanced Product Filtering
Users can filter products based on:
- Category
- Brand
- Price Range
- Vegetarian / Non-Vegetarian

### 🛒 Shopping Cart
Complete client-side shopping cart functionality:

- Add products
- Remove products
- Increase quantity
- Decrease quantity
- Automatic subtotal calculation
- Delivery charge calculation
- Total amount calculation
- Real-time cart updates

### 📱 Fully Responsive Design
Optimized for:

- Mobile Devices
- Tablets
- Laptops
- Desktop Screens

## Run the Project

1. Place all project files in the same folder.
2. Open **index.html** in any modern web browser.
3. Ensure an internet connection is available for loading Bootstrap and Google Fonts via CDN.

No installation, build process, or server configuration is required.

# 💻 How to Use

### Browse Products
Explore grocery items by scrolling through different product categories.

### Search Products
Use the search bar in the navigation menu to quickly locate products.

### Apply Filters
Filter products based on:
- Category
- Brand
- Price Range
- Diet Preference

### View Product Details
Click the **View** button on any product card to open a detailed product modal.

### Manage Shopping Cart
- Add products to the cart
- Increase or decrease quantities
- Remove unwanted products
- View updated subtotal, delivery fee, and total amount instantly

### Explore Offers
Browse promotional banners and discount offers using the carousel.
